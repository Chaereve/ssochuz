Cách vận hành

· Mọi nút "commit" sẽ ghi file JSON vào nhánh chính của repo → Cloudflare Pages tự build lại trong ~30–60 giây.
· Thêm chương: mở truyện → "+ Thêm chương cuối" hoặc "Dán hàng loạt" (mỗi chương ngăn cách bởi dòng chỉ chứa ---CHAP---, dòng đầu mỗi khối là tựa chương).
· Ảnh bìa dùng link ảnh ngoài (CDN, imgur, drive…); không cần upload file.
· Sao lưu: nút "Tải bản sao lưu" gộp registry + toàn bộ chương thành 1 file JSON giữ trong máy.
· Muốn đổi tên url (slug): sửa ô Slug rồi Lưu — url cũ sẽ 404, cân nhắc chia sẻ lại link.
