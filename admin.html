Kênh đăng bài

Bản này đăng trực tiếp lên Cloudflare KV qua Worker: bấm Lưu là người đọc thấy ngay, không cần chờ GitHub build/deploy. Cần đúng 2 thứ: URL Worker và ADMIN_KEY (khoá bạn tự đặt khi tạo Worker — xem worker/README.md). Khoá chỉ giữ trong máy bạn (localStorage), không gửi đi đâu khác.

Hướng dẫn nhanh 5 bước (bấm để mở)
  1. Cloudflare → Workers & Pages → KV → tạo namespace tên chuseoz, copy ID.
  2. Vào Workers & Pages → Create → Worker, dán nội dung worker/cms.js trong repo, Deploy.
  3. Trong Worker → Settings → Variables: thêm KV binding tên CZ_KV (chọn namespace ở bước 1) và secret ADMIN_KEY (tự đặt, ví dụ cz-2026-bimat).
  4. Dán URL Worker + ADMIN_KEY vào ô trên rồi bấm Kiểm tra & vào quản trị.
  5. Bấm Nạp dữ liệu lên KV (một lần) để đưa 62 truyện hiện có lên KV — hoặc chạy tools/push_to_kv.py. Sau đó web đọc từ KV; điền URL Worker vào window.CZ_API trong index/reader/admin.

Cách vận hành (bản KV — không cần build)

  1. Đăng bài: sửa xong bấm Lưu → ghi thẳng vào Cloudflare KV → người đọc thấy ngay (1–2 giây), không chờ GitHub build.
  2. Chương: “+ Thêm chương cuối” hoặc “Dán hàng loạt” (mỗi chương ngăn bởi dòng chỉ chứa ---CHAP---, dòng đầu là tựa chương). Danh sách luôn xếp mới nhất lên trên.
  3. Đồng bộ Blogger: nút “⟳ Đồng bộ từ Blogger” đọc lại trang /p/list-novel.html + các bài viết, cập nhật tình trạng, số chương, ngày cập nhật, lịch ra chương — rồi ghi vào KV. Dùng khi bạn đăng chương lên blogspot mà chưa muốn nhập tay.
  4. Nạp dữ liệu lên KV: chạy một lần đầu để đưa 62 truyện đang có trong repo lên KV (hoặc tools/push_to_kv.py ở máy).
  5. Sao lưu / phục hồi: “Tải bản sao lưu” gộp registry + toàn bộ chương thành 1 file JSON; “Phục hồi từ file” nạp lại và ghi lên KV.
  6. Ảnh bìa: dùng link ảnh ngoài (CDN, imgur, drive…), không cần upload.
  7. Số liệu đọc/thích: lấy từ Firebase cũ (chuseoz-library). Cần mở quyền đọc Firestore (xem worker/README.md §5) thì web mới hiện số thật — chưa mở thì web không hiện số nào cả.

Đổi tên url (slug): sửa ô Slug rồi Lưu — url cũ sẽ 404, cân nhắc chia sẻ lại link. Nếu chưa cấu hình Worker, admin vẫn mở được nhưng không lưu được — hãy làm 5 bước ở trang đầu.
